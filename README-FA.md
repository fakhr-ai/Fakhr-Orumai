# دستیار فخر اروم — بسته GitHub Pages

1. در GitHub یک مخزن جدید با نام دقیق `fakhr-ai.github.io` بسازید.
2. این ZIP را استخراج کنید.
3. همه فایل‌ها و پوشه‌های داخل `fakhr-ai-gh-pages` را در ریشه مخزن آپلود کنید؛ خود پوشه را به‌صورت پوشه تو در تو آپلود نکنید.
4. روی **Commit changes** بزنید.
5. در **Settings → Pages** گزینه **Deploy from a branch**، شاخه `main` و پوشه `/(root)` را انتخاب کنید.
6. پس از چند دقیقه سایت را در `https://fakhr-ai.github.io/` باز کنید.

`index.html` شامل لوگوی اختصاصی‌ای است که فرستادید. آدرس `fakhr-ai.github.io` فقط وقتی در دسترس خواهد بود که حساب یا سازمان GitHub مالک آن نام باشد. اگر نام کاربری‌تان هنوز `Ng2662` است، ابتدا باید نام کاربری را تغییر دهید یا از نام موجود خودتان استفاده کنید.

نکته امنیتی: کلید API را داخل فایل یا مخزن عمومی قرار ندهید. بدون اتصال به سرویس مدل زبانی، پاسخ‌های هوشمند ممکن است محدود باشند.
